1. CONTEXTO
Sistema de Controle Financeiro Familiar: backend FastAPI + MongoDB, frontend PWA
mobile first (pt-BR). Requisitos: HTTPS/TLS 1.2+, backup diário com retenção de
7 dias, disponibilidade 99%, job agendado (APScheduler) às 00:05
America/Sao_Paulo, orçamento gratuito ou baixo custo, preferência por região
São Paulo.

3. JOB ÀS 00:05 E HIBERNAÇÃO
- Render free hiberna por inatividade: NÃO garante o job às 00:05. Descartado
  para o scheduler.
- Fly.io: máquina com auto_stop_machines=false e min_machines_running=1 mantém
  o APScheduler ativo; fuso configurado no scheduler (America/Sao_Paulo), não
  dependente do TZ do host.
- Alternativa de contingência: cron externo (GitHub Actions schedule ou
  cron-job.org) chamando endpoint protegido por token (idempotente) às 00:05 BRT
  (03:05 UTC); tolera atraso de alguns minutos e serve também para acordar
  o Render free.

4. DECISÃO
- Backend: Fly.io, região gru (São Paulo), 1 máquina shared 256–512 MB sempre
  ligada, scheduler no mesmo processo.
- Banco: MongoDB Atlas M0 (AWS sa-east-1) na fase inicial + backup diário via
  mongodump agendado (retenção 7 dias). Migrar para M10 pelos gatilhos abaixo.
- Frontend: Cloudflare Pages, com _headers (HSTS, CSP, X-Content-Type-Options).
- Job 00:05: APScheduler no Fly.io; cron externo idempotente como redundância.

6. VARIÁVEIS DE AMBIENTE (nomes apenas, sem valores)
Comuns backend: APP_ENV, TZ_SCHEDULER=America/Sao_Paulo, MONGODB_URI,
MONGODB_DB_NAME, JWT_SECRET, JWT_ALGORITHM, ACCESS_TOKEN_EXPIRE_MINUTES,
CORS_ORIGINS, CRON_TRIGGER_TOKEN.
Fly.io: FLY_API_TOKEN (CI), secrets via "fly secrets set".
Render: RENDER_DEPLOY_HOOK_URL (CI), PYTHON_VERSION.
Railway: RAILWAY_TOKEN (CI), PORT.
Atlas: ATLAS_PROJECT_ID, ATLAS_PUBLIC_KEY, ATLAS_PRIVATE_KEY (apenas se usar API).
Backup: BACKUP_S3_ENDPOINT, BACKUP_BUCKET, BACKUP_ACCESS_KEY_ID,
BACKUP_SECRET_ACCESS_KEY, BACKUP_RETENTION_DAYS=7.
Frontend: VITE_API_BASE_URL. Cloudflare: CLOUDFLARE_API_TOKEN, CLOUDFLARE_ACCOUNT_ID (CI).
Todos guardados em secret stores dos provedores/CI; nunca versionados.

7. CONSEQUÊNCIAS
+ Custo baixo (~US$4–7/mês), baixa latência (gru), sem cold start.
+ HTTPS automático em todas as camadas.
- M0 sem backup nativo: rotina própria obrigatória e teste de restauração.
- M0 limitado a 512 MB e sem SLA; Fly.io exige cartão de crédito.
- Lock-in moderado (Dockerfile padrão mitiga).

8. GATILHOS DE MIGRAÇÃO (RK-05)
- Dados > 400 MB (80% do M0) ou ops/s próximas de 100: migrar para Atlas M10
  (ou Flex/M2-M5 se disponível).
- Ativação de Open Finance / dados sensíveis de terceiros: migrar para M10
  com backup gerenciado.
- Disponibilidade medida < 99% por 2 meses ou RAM > 80% sustentada: subir
  tamanho da máquina ou migrar para Render/Railway pago.
- Aumento de preço > 30% em qualquer provedor: reavaliar alternativas.
Plano: backend em Docker (portável); migração de banco via mongodump/mongorestore;
DNS próprio com TTL baixo para troca sem indisponibilidade.
