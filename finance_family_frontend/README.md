# Financeiro Web (PWA)

PWA mobile first: Vue 3 + Vite + TypeScript + Pinia, testes com Jest. Framework escolhido: Vue.

## Como rodar

```
copy .env.example .env
npm install
npm run dev
```

## Qualidade

```
npm run lint ; npm run format ; npm test
```

Convenções de branch e commit: as mesmas do backend (Conventional Commits; `main`/`develop`, `feature/*`, `fix/*`; PR exige revisão e CI verde). Veja o CONTRIBUTING.md do backend.
